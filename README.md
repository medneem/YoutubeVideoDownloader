# YoutubeVideoDownloader

[![Build Windows](https://github.com/medneem/YoutubeVideoDownloader/actions/workflows/build-windows.yml/badge.svg)](https://github.com/medneem/YoutubeVideoDownloader/actions/workflows/build-windows.yml)

**YoutubeVideoDownloader** — бесплатная портативная программа с русским интерфейсом для скачивания видео и аудио с YouTube на Windows 10/11 x64. Без рекламы, подписок и необходимости устанавливать Python.

> Статус: первая версия (MVP). Это независимый проект, не связанный с YouTube или Google.

## Возможности

- Видео в MP4 с выбором максимального разрешения: автоматически, 4K/2160p, 1440p, 1080p, 720p, 480p и 360p (при наличии у источника).
- Извлечение звуковой дорожки в MP3, 192 кбит/с.
- Выбор папки сохранения, отображение прогресса, скорости и примерного оставшегося времени.
- Кнопки **«Скачать»**, **«Отменить»** и **«⚙ Настройки»**.
- В окне настроек: включение/выключение **HTTP/HTTPS-прокси** и указание его адреса, например \`http://127.0.0.1:8118\`.
- Все настройки хранятся в **config.json рядом с YoutubeVideoDownloader.exe**, создаются при первом запуске и автоматически сохраняются.
- В готовом Windows-архиве уже присутствуют **FFmpeg, FFprobe, Deno** и Python-зависимости.

Списки воспроизведения и пакетная загрузка пока не поддерживаются: одна ссылка — одно видео.

## Скачать готовую программу

1. Перейдите в [Actions → Build Windows](https://github.com/medneem/YoutubeVideoDownloader/actions/workflows/build-windows.yml).
2. Выберите **успешный** запуск workflow (зелёная галочка).
3. Внизу страницы в **Artifacts** нажмите \`YoutubeVideoDownloader-windows-x64\`.
4. GitHub скачает ZIP-артефакт. Распакуйте его и лежащий внутри файл \`YoutubeVideoDownloader-windows-x64.zip\`.
5. Войдите в папку \`YoutubeVideoDownloader\` и запустите \`YoutubeVideoDownloader.exe\`.

Внутри папки приложения должны быть:

\`\`\`text
YoutubeVideoDownloader/
├── YoutubeVideoDownloader.exe
├── ffmpeg.exe
├── ffprobe.exe
├── deno.exe
└── _internal/                 # Python, PySide6, yt-dlp, yt-dlp-ejs и зависимости
\`\`\`

**Важно:** Не извлекайте один \`.exe\` из папки: это сборка \`--onedir\`, ей нужны остальные файлы. Программа не подписана цифровой подписью; Windows SmartScreen может запросить подтверждение. В Actions нужно войти в GitHub, чтобы скачать артефакт. Артефакты хранятся **14 дней** после сборки.

## Настройки рядом с программой

При первом запуске программа создаёт файл \`config.json\` в папке самого EXE (в режиме разработки — рядом с \`main.py\`). Например:

\`\`\`json
{
  "download_dir": "C:\\Users\\User\\Downloads",
  "mode": "video",
  "quality": "1080",
  "proxy_enabled": true,
  "proxy_url": "http://127.0.0.1:8118"
}
\`\`\`

Чтобы включить прокси, нажмите **«⚙ Настройки»**, поставьте галочку **«Использовать HTTP-прокси»** и введите полный URL с протоколом и портом. Снимите галочку, если хотите скачивать напрямую. Настройка применяется к следующим загрузкам; во время активной загрузки кнопка недоступна.

**Переносимость:** можно скопировать всю папку вместе с \`config.json\` на другой ПК. Файл должен лежать в папке, доступной для записи. Не помещайте программу в защищённый \`Program Files\` без соответствующих разрешений. Путь загрузок на другом ПК может потребовать изменения.

**Приватность:** \`config.json\` не отправляется в репозиторий (указан в \`.gitignore\`). Если в URL прокси встроены логин и пароль, они хранятся в этом файле **в открытом виде** — ограничьте доступ к папке и никому не передавайте такой конфиг.

## Работа с YouTube

Вставьте ссылку, выберите **Видео MP4** или **Аудио MP3**, при необходимости задайте качество и папку загрузки, затем нажмите **«Скачать»**.

Для полноценной обработки современных видеопотоков YouTube используется [yt-dlp](https://github.com/yt-dlp/yt-dlp) вместе с [EJS](https://github.com/yt-dlp/yt-dlp/wiki/EJS) и JavaScript-движком Deno. FFmpeg необходим для объединения видеопотока с аудио и преобразования MP3. Не каждое видео или выбранное качество гарантированно доступны: возможны ограничения со стороны YouTube, географии, учётной записи или правообладателя.

## Разработка

Стек: **Python 3.13 · PySide6/Qt · yt-dlp[default] · Deno · FFmpeg · PyInstaller · GitHub Actions**.

Установите Python 3.13. Для локального запуска обеспечьте доступность \`ffmpeg\` и \`deno\` в \`PATH\`, либо разместите их \`.exe\` рядом с \`main.py\`.

\`\`\`powershell
git clone https://github.com/medneem/YoutubeVideoDownloader.git
cd YoutubeVideoDownloader
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-build.txt
python main.py
\`\`\`

Запуск тестов:

\`\`\`powershell
python -m unittest discover -s tests -v
\`\`\`

## CI/CD: ZIP в успешном pipeline

Workflow [Build Windows](.github/workflows/build-windows.yml) автоматически запускается при \`push\` в \`main\`, при pull request, а также вручную (кнопка **Run workflow**).

Этапы:
1. Установка Python 3.13 и зависимостей.
2. Проверка синтаксиса исходников и выполнение тестов.
3. Сборка Windows-приложения PyInstaller в режиме **onedir**.
4. Загрузка и добавление в папку приложения \`ffmpeg.exe\`, \`ffprobe.exe\`, \`deno.exe\`.
5. Проверка наличия файлов и создание ZIP всей папки.
6. Публикация \`YoutubeVideoDownloader-windows-x64.zip\` в **Actions → Artifacts**.

**Требование:** если тесты не прошли, отсутствует EXE или бинарные зависимости, либо не сформирован архив, сборка должна завершиться ошибкой. Шаг \`upload-artifact\` использует \`if-no-files-found: error\`. Успешный pipeline тем самым обязан содержать готовый архив.

> GitHub Actions собирает портативную программу, но это ещё не полноценный интеграционный тест скачивания с YouTube. Реальную загрузку следует проверить вручную на Windows.
